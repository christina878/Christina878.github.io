# Open Library Book Search Project

This web app allows users to search for books using the Open Library REST API.  
It uses only HTML, Bootstrap, and Vanilla JavaScript.

## Features
- Search for books  
- View book details  
- Covers, authors, subjects, description  
- Uses multiple API endpoints  

## Endpoints Used
- Search: https://openlibrary.org/search.json?q=QUERY  
- Book Details: https://openlibrary.org/works/BOOKID.json  
- Author Info: https://openlibrary.org/authors/AUTHORID.json  
- Covers: https://covers.openlibrary.org/b/id/COVERID-L.jpg  

## How to Run
Open `index.html` in your browser or host on GitHub Pages.
