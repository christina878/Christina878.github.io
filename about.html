Book Finder

About This Project

This website was created as part of my final project for my Web Development class. The goal was to practice using HTML, Bootstrap, and JavaScript to connect with a real API.

The API I used is the Open Library API. It provides public data about books, authors, and publishing history.

Pages Included

  • Home Page: Search for books using a title.
  • Details Page: Shows more information about the selected book.
  • About Page: Explains the purpose and tools used in the project.
